# community plugins

RU:
плагины для exteraGram / AyuGram от других авторов. здесь только ссылки: код лежит в репозиториях авторов и распространяется под их лицензиями. перед установкой проверяйте исходники и совместимость с вашей версией клиента.
хотите добавить свой плагин? откройте PR с новой строкой в нужной таблице (нужны ссылка на репо, автор и открытая лицензия).

EN:
exteraGram / AyuGram plugins made by other authors. links only: the code lives in the authors' repos under their own licenses. check the sources and compatibility with your client version before installing.
want to add your plugin? open a PR with a new row in the right table (repo link, author and an open-source license are required).
