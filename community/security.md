# безопасность: как проверять чужие плагины

> плагин exteraGram — это Python-код, который работает внутри клиента с полным доступом к аккаунту: читать переписку, отправлять сообщения, менять профиль, ходить в сеть. перед установкой или копированием кода из чужого плагина его стоит хотя бы пролистать.

---

## исключённые плагины

при разборе пачки плагинов для этого репо два файла не прошли проверку и сюда не попали.

### копия Time Nickname (`time_nickname.plugin`) — заражена

оригинальный Time Nickname от @mishabotov чистый (632 строки, сеть только через API Telegram), он есть в [каталоге](README.md). заражена одна из копий, которая ходит по чатам: в конец файла дописан блок `# === injected ===`:

```python
_ld=b"""UEf8tzVc5ec4T+Ki..."""          # base64
_raw=_b64.b64decode(_ld)
_k=bytes.fromhex("5a2e91c7")              # XOR-ключ
_dec=bytes(c^_k[i%len(_k)] for i,c in enumerate(_raw))
exec(compile(_dec.decode("utf-8"),"<x>","exec"),globals())
```

если расшифровать (не выполняя), внутри загрузчик: он генерирует id устройства, сохраняет его в `files/.did`, стучится на `http://78.17.115.65:8081/api/v1/rt` с заголовком `X-Plugin-Token`, скачивает оттуда Python-код и выполняет его через `exec` в глобальном неймспейсе плагина. то есть владелец сервера может в любой момент выполнить на устройстве любой код с доступом к аккаунту.

отличить просто: в чистом файле нет `exec`, `_ld=`, `fromhex` и обращений к `78.17.115.65`. **если у вас стояла заражённая копия:** удалите плагин, зайдите в «Настройки → Устройства» и завершите незнакомые сеансы.

### TheLooker (`TheLooker.plugin`)

по описанию «подглядывает, в каком чате сидит собеседник». вся логика лежит не в плагине, а в закрытом `Tracker.dex`, который при каждом запуске скачивается с `storage.yandexcloud.net/4plugins/DOXGRAM…` и грузится через `InMemoryDexClassLoader`. автор может подменить этот файл когда угодно, а цель плагина (слежка за другим человеком) сама по себе не то, что стоит распространять.

## на что смотреть в чужом плагине

| признак | почему опасно | нормальный вариант |
|---|---|---|
| `exec(` / `eval(` / `compile(` с данными из сети или из расшифрованной строки | выполнение кода, которого нет в файле | REPL-плагины (Termux Bridge, MandreLib hot-reload) выполняют код, который пишет сам пользователь |
| длинная base64-строка + `bytes.fromhex` + XOR | так прячут код от просмотра | base64 с DEX внутри (см. [java-dex.md](java-dex.md)) — обычная практика, но DEX стоит декомпилировать |
| `urllib.request` / `requests` на голый IP с портом (`http://1.2.3.4:8081`) | нормальные сервисы почти всегда ходят по домену и https | API известных сервисов: Groq, Deepgram, Spotify, Steam |
| скачивание `.dex` / `.py` / `.whl` при запуске | код плагина меняется без вашего ведома | всё нужное вшито в сам файл |
| доступ к `tgnet.dat`, `auth_key`, `getAuthKey` | это ключи сессии, по ним можно войти в аккаунт | плагинам это не нужно почти никогда |
| блок кода в самом конце файла после `# end` или с другим стилем | так обычно выглядит инъекция в чужой плагин | — |

как быстро проверить файл без запуска (на ПК):

```bash
grep -nE 'exec\(|eval\(|compile\(|urlopen|requests\.(get|post)|InMemoryDexClassLoader|fromhex|[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+:[0-9]+' plugin.plugin
```

каждое совпадение стоит открыть и понять, откуда берутся данные.

### плагины-проверялки

| плагин | автор | как проверяет |
|---|---|---|
| Plugin Security | @mihailkotovski & @mishabotov | локальные эвристики (exec, base64, загрузка DEX, POST на чужие сервера, Bot API) плюс разбор кода через Google Gemini или OpenAI-совместимый API. ключ API ваш, код проверяемого плагина уходит этому сервису |
| Plugin Verifier | @JasonVurhyz | локальный разбор кода, распаковка вшитых DEX/архивов и строк из них (без запуска). по SHA-256 сверяет плагин с базой проверенных плагинов автора на Supabase, подгружает оттуда список скамеров. если плагин ссылается на удалённый `.dex`/`.zip`, скачивает его только для анализа |

оба плагина при разборе вредоносного кода не содержали. это хорошая первая проверка, но не гарантия: код, который скачивается с сервера уже после установки (как в заражённой копии Time Nickname), статический анализ увидит только как подозрительный запрос.

## не вредоносно, но стоит знать

- **Pomme, Translatica Pro, Nowfy Lite** (@AGeekApple) подтягивают иконки и ленту новостей с `*.meyankut.workers.dev`. в Pomme есть код отправки статистики установок на `geekstats.meyankut.workers.dev` (название плагина, версия, клиент и его версия), но в разобранной версии токен пустой, и отправка выключена.
- **Custom Profile** (@RoflPlugins) работает через свой сервер `customprofile.pixivdl.net`. Туда уходят ваш user id и данные привязанных сервисов (Spotify, VK, Яндекс Музыка, SoundCloud), когда вы их подключаете.
- **Heroku Host** (@swagnonher & @codrago) скачивает и запускает юзербот Heroku с GitHub. у юзербота полный доступ к аккаунту, ставьте только если понимаете, что это.
- **Termux Bridge** (@S1mclick) открывает сокет на `127.0.0.1` и выполняет присланный из Termux Python-код. он защищён токеном из настроек, но любое приложение, которое этот токен узнает, получит доступ к клиенту.
- **Device Fingerprint Spoofer** (@Daxo_OS) подменяет модель устройства и версию приложения, которые видит сервер Telegram. это нарушает обычное поведение клиента и может выглядеть подозрительно для антиспама Telegram.
